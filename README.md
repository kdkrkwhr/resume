# 김동기 이력서 페이지

GitHub Pages에 올릴 수 있는 정적 이력서 사이트입니다. 별도 빌드나 패키지 설치가 필요하지 않습니다.

## 미리보기

`index.html`을 브라우저로 열거나, 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속합니다.

## 게시

1. 개인 GitHub 계정에서 새 공개 저장소를 만듭니다. 예: `resume`.
2. **이 폴더의 파일만** 새 저장소의 루트에 올립니다. 회사 프로젝트 저장소 전체를 올리지 마세요.
3. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main / (root)**를 선택합니다.
4. 주소는 일반적으로 `https://<사용자명>.github.io/<저장소명>/`입니다.

상대 경로(`./style.css`)를 사용하므로 프로젝트 페이지와 사용자 페이지 양쪽에서 동작합니다.

## 공개 전 확인

- 현재 직책과 기간, 공개 가능한 업무 범위를 본인이 확인합니다.
- 프로젝트 데모·소스·블로그 링크가 원하는 공개 범위인지 확인합니다.
- 이 페이지에는 개인 연락처, 생년월일, 회사 내부 저장소·자료, 검증되지 않은 성과 수치를 포함하지 않았습니다.
